# Lishe Kwa Mtoto website

Static site. Open `index.html` or deploy the folder as-is (Firebase, Hosting, Netlify, any web host).

## Editing
Pages are generated by `build.py` (Python 3) so the header, footer and SEO tags stay identical everywhere.
Edit the `pages_*.py` files or `build_lib.py`, then run `python3 build.py`. The generated `.html` files can also be edited directly.

## Set before launch (build_lib.py)
- `SITE_URL`: currently https://lishekwamtotokenya.org (used for canonical URLs, Open Graph, sitemap). Change if the live domain differs.
- `SOCIAL`: add real Facebook/X/Instagram/LinkedIn/YouTube URLs. Empty ones are not shown (no dead links).

## International donations
The donate page lets visitors pick from 17 currencies (KES, USD, EUR, GBP, CAD, AUD, CHF, SEK, NOK, DKK, JPY, CNY, INR, AED, ZAR, UGX, TZS).
It shows the Kenyan shilling equivalent and children fed, using live rates from open.er-api.com with an approximate fallback table (edit `rates` in `pages_forms.py`).
Online card payments still go through PayNecta, which takes the amount in KES. Please confirm with PayNecta that international cards are accepted.
To add PayPal, Stripe Payment Links, Wise or similar, put the URL in `INTL_PAY_LINKS` in `build_lib.py` and rebuild; a button appears for each.
